# Agent 学习资源清单

这是一份面向大模型应用开发的学习资料整理，覆盖 Agent 入门、底层原理、工程实现和源码阅读。建议先完成入门内容，再根据自己的项目方向选择深入主题。

## 入门

- [Agent 入门](https://hello-agents.datawhale.cc/#/)：从基本概念和实践案例开始了解 Agent。
- [前端转 Agent](https://mp.weixin.qq.com/mp/appmsgalbum?action=getalbum&album_id=4588106487163617281)：面向前端开发者的 Agent 学习路线和实践资料。

## 原理与系统设计

- [图解大模型](https://book.douban.com/subject/37339504/)：通过图示理解大模型、Transformer 和生成式 AI 的基础原理。

## 工程实践

- [Pi 引擎](https://dg-ai-notes.pages.dev/)：记录 Pi 相关的 AI 工程实践和技术思考。
- [像 Jupyter 一样写一个 nano-pi](https://pi-from-scratch.vercel.app/)：从头实现一个轻量级 Agent，适合边读边动手。

## 源码阅读

- [pi-agent-core 源码导读](https://books.antinomie.org/pi/)：深入阅读 `pi-agent-core` 的实现，理解 Agent 运行时的关键模块。

## 推荐学习顺序

1. 先阅读 Agent 入门资料，建立基本概念。
2. 再学习大模型和 Agent 的原理，理解工具调用、上下文和记忆等机制。
3. 通过 nano-pi 等项目动手实现核心流程。
4. 最后结合源码导读，分析成熟实现中的工程取舍。

资源会持续补充，建议在阅读时同步记录自己的实验结果和问题。
